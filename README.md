# Smart Parking System

Real-time parking slot detection using Arduino and ultrasonic sensors.

## Overview
Designed a real-time embedded parking system using ultrasonic sensors for automated slot detection and monitoring. Integrated hardware and software for automated control using Arduino.

## Tech Stack
- Arduino
- Ultrasonic Sensors (HC-SR04)
- Embedded C / Arduino IDE
- LED Indicators

## Features
- Real-time parking slot detection using ultrasonic sensors
- Automated control and monitoring system
- Sensor-based real-time data acquisition and control logic
- Signal-based detection and system validation
- Serial monitor output for slot status
